2. Zweck und Rechtsgrundlage

Die Website demonstriert ein Software-Projekt aus meinem Portfolio (Verarbeitung einer Zahlung zu einer Rechnung). Die Verarbeitung der unten genannten Daten erfolgt auf Grundlage meines berechtigten Interesses an der Vorführung dieses Projekts und an einem sicheren Betrieb der Website (Art. 6 Abs. 1 lit. f DSGVO).

3. Aufruf der Website (Cloudflare, Hosting)

Alle Aufrufe laufen über Cloudflare (Cloudflare, Inc., USA) als Netzwerk- und Schutzdienst (Weiterleitung, Abwehr von Angriffen). Dabei verarbeitet Cloudflare technisch notwendige Daten wie IP-Adresse, Zeitpunkt, aufgerufene Adresse und Browser-Kennung. Cloudflare ist unter dem EU-US Data Privacy Framework zertifiziert. Der Server selbst wird bei Oracle Cloud Infrastructure in einem Rechenzentrum in Frankfurt am Main betrieben.

4. Demo-Zahlung (Stripe)

Die Zahlungsseite wird von Stripe bereitgestellt (Stripe Payments Europe, Ltd., Irland; checkout.stripe.com) und läuft ausschließlich im Testmodus: es wird kein Geld bewegt, nur Testkarten werden angenommen. Auf der Zahlungsseite geben Sie einen beliebigen Namen und die Daten der Testkarte ein; die E-Mail-Adresse ist vorausgefüllt und erfunden. Stripe setzt auf seiner eigenen Seite eigene Cookies. Stripe speichert die Testzahlung (mit dem eingegebenen Namen) dauerhaft im Test-Konto des Betreibers; die nächtliche Löschung auf diesem Server erfasst diese Daten bei Stripe nicht. Bitte geben Sie deshalb keinen echten Namen ein.

5. Daten auf diesem Server und Speicherdauer

Für Ihre Ergebnisseite speichert der Server: den eingegebenen Namen, die erfundene Demo-E-Mail-Adresse, Betrag, Rechnungsnummer und Zeitpunkte der Verarbeitung sowie einen Hash (keine Kopie) Ihres persönlichen Ergebnis-Links. Die Rechnungs-E-Mail landet in einem internen Testpostfach (Mailpit) auf demselben Server und wird nie an eine echte Adresse gesendet. Ihre IP-Adresse wird nicht in der Datenbank gespeichert.

  • Datenbank und Testpostfach: Löschung jede Nacht um 02:30 Uhr.
  • Technische Fehlerprotokolle der Automatisierung (n8n): nur bei Fehlern, höchstens 48 Stunden; sie können die Anfragedaten einschließlich der von Cloudflare übermittelten IP-Adresse enthalten.
  • Verschlüsselte Datensicherung: täglich um 03:00 Uhr, 14 Tage aufbewahrt; sie enthält höchstens die Daten, die zwischen 02:30 und 03:00 Uhr entstanden sind.

6. Benachrichtigungen

Demo-Zahlungen lösen keine Nachricht an Messenger-Dienste aus. Die Telegram-Nachricht auf der Ergebnisseite ist nur eine Vorschau. Wird das Tageslimit der Demo erreicht, erhält der Betreiber eine Benachrichtigung ohne personenbezogene Daten.
